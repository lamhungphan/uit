Formal Definition

$$f(n) = \mathcal{O}(g(n))$$

$f(n) = \mathcal{O}(g(n))$ means there exist positive constants $c > 0$ and $n_0 \ge 1$ such that:

$$f(n) \le c \cdot g(n) \quad \text{for all } n \ge n_0$$

TikZ Asymptotic Plot Code

Standalone LaTeX TikZ snippet matching the Big-O curves for academic documents and papers.

% LaTeX / TikZ preamble required:
% \usepackage{pgfplots}
% \pgfplotsset{compat=1.18}

\begin{tikzpicture}
  \begin{axis}[
    axis lines = left,
    xlabel = {$n$},
    ylabel = {Operations},
    xmin = 0, xmax = 30,
    ymin = 0, ymax = 120,
    domain = 0:30,
    samples = 100,
    grid = major,
    grid style = {dashed, gray!20},
    legend pos = north west,
    legend style = {draw=none, fill=slate!10, font=\small},
    width = 11cm, height = 7.5cm
  ]

  % Highlight Region n >= n0
  \addplot [draw=none, fill=emerald!10, domain=10:30] {4*x} \closedcycle;

  % Function f(n)
  \addplot [color=indigo, ultra thick, domain=0:30] {3*x + 10};
  \addlegendentry{$f(n) = 3n + 10$}

  % Function c * g(n)
  \addplot [color=emerald, ultra thick, domain=0:30] {4*x};
  \addlegendentry{$c \cdot g(n) = 4n$}

  % Threshold line n0
  \draw [dashed, color=amber, ultra thick] (axis cs:10,0) -- (axis cs:10,120);
  \node [above, color=amber, font=\small] at (axis cs:10,0) {$n_0 = 10$};

  \end{axis}
\end{tikzpicture}
