## PHẦN C – Tính định thức

> **Cách làm (quy tắc Sarrus cho ma trận 3×3):** viết lại ma trận rồi chép thêm 2 cột đầu sang bên phải:
> ```
> [ a  b  c ] a  b
> [ p  q  r ] p  q
> [ u  v  w ] u  v
> ```
> det = (aqv + bru + cpw) − (bvp + cqu + arw)
> = (tổng 3 đường chéo chính) − (tổng 3 đường chéo phụ).

### Bài 1 — det = 239

```
[ 3  -5   1 ]
[10  -6   7 ]
[ 4  -9   8 ]
```

| | | |
|---|---|---|
| **Đường chéo chính** | 3·(−6)·8 = −144 | (−5)·7·4 = −140 | 1·10·(−9) = −90 |
| | | | **Tổng = −374** |
| **Đường chéo phụ** | 1·(−6)·4 = −24 | 3·7·(−9) = −189 | (−5)·10·8 = −400 |
| | | | **Tổng = −613** |

det = −374 − (−613) = **239**

### Bài 2 — det = 30

```
[ 3  -1   5 ]
[ 4  -7  -2 ]
[ 5  -4   3 ]
```

**Chính:** 3·(−7)·3 = −63; (−1)·(−2)·5 = 10; 5·4·(−4) = −80 → **tổng = −133**
**Phụ:** 5·(−7)·5 = −175; 3·(−2)·(−4) = 24; (−1)·4·3 = −12 → **tổng = −163**

det = −133 − (−163) = **30**

### Bài 3 — det = (a−b)(a−c)(c−b)

```
[  1  a  bc ]
[  1  b  ac ]
[  1  c  ab ]
```

**Chính:** 1·b·ab = ab²; a·ac·1 = a²c; bc·1·c = bc² → **tổng = ab² + a²c + bc²**
**Phụ:** bc·b·1 = b²c; 1·ac·c = ac²; a·1·ab = a²b → **tổng = b²c + ac² + a²b**

det = ab² + a²c + bc² − (b²c + ac² + a²b)
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;= ab² − a²b + a²c − ac² + bc² − b²c
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;= **(a−b)(a−c)(c−b)**  (= (b−a)(c−a)(c−b))

*Kiểm tra nhanh (a=1, b=2, c=3):* (1−2)(1−3)(3−2) = (−1)(−2)(1) = 2 ✓

### Bài 4 — det = (b−a)(c−a)(c−b)

```
[  1   1   1 ]
[  a   b   c ]
[ a²  b²  c² ]
```

**Chính:** 1·b·c² = bc²; 1·c·a² = ca²; 1·a·b² = ab² → **tổng = bc² + ca² + ab²**
**Phụ:** 1·b·a² = ba²; 1·c·b² = cb²; 1·a·c² = ac² → **tổng = ba² + cb² + ac²**

det = bc² + ca² + ab² − (ba² + cb² + ac²)
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;= **(b−a)(c−a)(c−b)**

(Đây là **ma trận Vandermonde**: det = tích ∏(xⱼ − xᵢ) với x₁ = a, x₂ = b, x₃ = c.)

### Bài 5 — det = (a−b)(a−c)(c−b)

```
[ a  a²  1 ]
[ b  b²  1 ]
[ c  c²  1 ]
```

**Chính:** a·b²·1 = ab²; a²·1·c = a²c; 1·b·c² = bc² → **tổng = ab² + a²c + bc²**
**Phụ:** 1·b²·c = b²c; a·1·c² = ac²; a²·b·1 = a²b → **tổng = b²c + ac² + a²b**

det = ab² + a²c + bc² − (b²c + ac² + a²b)
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;= **− (a−b)(a−c)(b−c) = (a−b)(a−c)(c−b)**

## PHẦN D – Phần bù đại số

> **Cách làm:**
> - `A(i|j)` = ma trận nhận được sau khi **xóa dòng i và cột j** của A.
> - Phần bù đại số: **cᵢⱼ = (−1)^(i+j) · det[A(i|j)]**.
> - Dấu (−1)^(i+j): (+) nếu i+j chẵn, (−) nếu i+j lẻ.

### Ví dụ mẫu — A = [[5, −1, 4],[7, 2, −6],[−9, 10, 3]]

**Tìm các ma trận con:**
- **A(2|3)** (xóa dòng 2, cột 3):
```
[ 5  −1 ]
[−9  10 ]
```
- **A(3|1)** (xóa dòng 3, cột 1):
```
[−1  4 ]
[ 2 −6 ]
```
- **A(1|2)** (xóa dòng 1, cột 2):
```
[ 7 −6 ]
[−9  3 ]
```

**Tính các phần bù đại số:**
- **c₂₃** = (−1)^(2+3) · det A(2|3) = −(5·10 − (−1)·(−9)) = −(50 − 9) = **−41**
- **c₃₁** = (−1)^(3+1) · det A(3|1) = +((−1)·(−6) − 4·2) = (6 − 8) = **−2**
- **c₁₂** = (−1)^(1+2) · det A(1|2) = −(7·3 − (−6)·(−9)) = −(21 − 54) = **33**

### Ví dụ 1 — A = [[4, 3, 10],[6, −1, 7],[−9, 5, 3]]

- **c₂₁** = (−1)^3 · det A(2|1); A(2|1) = [[3, 10],[5, 3]] → det = 9 − 50 = −41 → **c₂₁ = −(−41) = 41**
- **c₃₁** = (−1)^4 · det A(3|1); A(3|1) = [[3, 10],[−1, 7]] → det = 21 − (−10) = 31 → **c₃₁ = 31**
- **c₁₁** = (−1)^2 · det A(1|1); A(1|1) = [[−1, 7],[5, 3]] → det = −3 − 35 = −38 → **c₁₁ = −38**

### Ví dụ 2 — B = [[8, −3, −7],[6, 10, 5],[9, 2, −1]]

- **c₂₃** = (−1)^5 · det B(2|3); B(2|3) = [[8, −3],[9, 2]] → det = 16 − (−27) = 43 → **c₂₃ = −43**
- **c₃₃** = (−1)^6 · det B(3|3); B(3|3) = [[8, −3],[6, 10]] → det = 80 − (−18) = 98 → **c₃₃ = 98**
- **c₁₃** = (−1)^4 · det B(1|3); B(1|3) = [[6, 10],[9, 2]] → det = 12 − 90 = −78 → **c₁₃ = −78**

### Ví dụ 3 — C = [[4, −2, 9],[10, −8, 3],[1, 6, −5]]

- **c₂₁** = (−1)^3 · det C(2|1); C(2|1) = [[−2, 9],[6, −5]] → det = 10 − 54 = −44 → **c₂₁ = 44**
- **c₂₂** = (−1)^4 · det C(2|2); C(2|2) = [[4, 9],[1, −5]] → det = −20 − 9 = −29 → **c₂₂ = −29**
- **c₃₂** = (−1)^5 · det C(3|2); C(3|2) = [[4, 9],[10, 3]] → det = 12 − 90 = −78 → **c₃₂ = 78**

### Ví dụ 4 — D = [[3, −1, 8, 6],[9, 0, 2, 5],[3, 7, −1, −8],[10, 6, 4, −2]]

- **c₁₄** = (−1)^5 · det D(1|4); D(1|4) = [[9, 0, 2],[3, 7, −1],[10, 6, 4]]
  - Chính: 9·7·4 = 252; 0·(−1)·10 = 0; 2·3·6 = 36 → 288
  - Phụ: 2·7·10 = 140; 9·(−1)·6 = −54; 0·3·4 = 0 → 86
  - det = 288 − 86 = 202 → **c₁₄ = −202**
- **c₂₃** = (−1)^5 · det D(2|3); D(2|3) = [[3, −1, 6],[3, 7, −8],[10, 6, −2]]
  - Chính: 3·7·(−2) = −42; (−1)·(−8)·10 = 80; 6·3·6 = 108 → 146
  - Phụ: 6·7·10 = 420; 3·(−8)·6 = −144; (−1)·3·(−2) = 6 → 282
  - det = 146 − 282 = −136 → **c₂₃ = −(−136) = 136**

### Ví dụ 5 — E = [[2, 5, 10, 0],[6, −7, −1, 3],[4, 9, 8, 2],[5, −1, 3, 7]]

- **c₃₄** = (−1)^7 · det E(3|4); E(3|4) = [[2, 5, 10],[6, −7, −1],[5, −1, 3]]
  - Chính: 2·(−7)·3 = −42; 5·(−1)·5 = −25; 10·6·(−1) = −60 → −127
  - Phụ: 10·(−7)·5 = −350; 2·(−1)·(−1) = 2; 5·6·3 = 90 → −258
  - det = −127 − (−258) = 131 → **c₃₄ = −131**
- **c₃₂** = (−1)^5 · det E(3|2); E(3|2) = [[2, 10, 0],[6, −1, 3],[5, 3, 7]]
  - Chính: 2·(−1)·7 = −14; 10·3·5 = 150; 0·6·3 = 0 → 136
  - Phụ: 0·(−1)·5 = 0; 2·3·3 = 18; 10·6·7 = 420 → 438
  - det = 136 − 438 = −302 → **c₃₂ = −(−302) = 302**
