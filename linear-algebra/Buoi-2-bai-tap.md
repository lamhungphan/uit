## Phần A – Tìm hạng ma trận

**Bài 1.** Cho ma trận:
```
     [ 2  -1   0   3   5 ]
     [ 2   2   1   0   4 ]
A =  [ 4   1  -3   6   7 ]
     [ 8   0   1  -2  -4 ]
```
Tìm r(A).

---

**Bài 2.** Cho ma trận:
```
     [ 1  -2   0   3 ]
     [ 5   8   1   9 ]
A =  [ 7  -6   1   5 ]
     [ 4   0   2  10 ]
     [ 3   1   0  -1 ]
```
Tìm r(A).

---

**Bài 3.** Cho ma trận:
```
     [ 1  -1   3 ]
A =  [ 2   m   1 ]
     [ 1   3   m ]
```
Tìm và biện luận hạng của A theo tham số thực m.

---

**Bài 4.** Cho ma trận:
```
     [ m-5   m    m ]
A =  [  m   2m   10 ]
     [ -m    m  m-3 ]
```
Tìm và biện luận hạng của A theo tham số thực m.

---

**Bài 5.** Cho ma trận:
```
     [ 3   1   1   4 ]
     [ 4  10   1   m ]
A =  [ 1   7  17   3 ]
     [ 2   2   4   1 ]
```
Tìm và biện luận hạng của A theo tham số thực m.

## Phần D – Lũy thừa ma trận vuông

**Bài 1.** Cho ma trận:
```
     [ 0  1  0 ]
A =  [ 0  0  1 ]
     [ 0  0  0 ]
```
Tìm A², A³ và A⁴.

---

**Bài 2.** Cho ma trận:
```
     [ 2  -1 ]
A =  [ 3  -2 ]
```
Tìm Aᵏ, ∀k ≥ 0, k ∈ ℤ.

---
